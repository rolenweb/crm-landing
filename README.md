# Styber — лендинг «Интеграция CRM и автоматизация бизнеса»

Одностраничный лендинг для услуг по интеграции CRM-систем (Bitrix24, amoCRM) и автоматизации бизнес-процессов: подключение Telegram, WhatsApp, 1С, Email, IP-телефонии и других сервисов через API.

## Структура проекта

```
.
├── index.html      # разметка страницы (Hero, Проблемы, Интеграции, Этапы работы, FAQ, CTA-форма и т.д.)
├── style.css       # стили: CSS-переменные, адаптивная вёрстка, анимации
├── script.js       # интерактив: reveal-анимации, аккордеон FAQ, валидация формы, плавный скролл
└── favicon.svg     # фавикон (буква S в стиле логотипа)
```

## Технологии

Чистые HTML/CSS/JS без фреймворков и сборщиков. Единственная внешняя зависимость — шрифт Inter, подключаемый через Google Fonts.

## Запуск локально

Проект не требует сборки — достаточно открыть `index.html` в браузере или поднять локальный сервер, например:

```bash
npx serve .
```

## Известные ограничения

- Форма заявки (`#leadForm`) в текущем виде только валидирует поля и показывает сообщение об успехе — отправка данных на бэкенд/в CRM пока не реализована.
